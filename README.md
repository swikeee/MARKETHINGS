# MARKETHINGS

*Everything Marketing in One Place.*

Dashboard satu halaman untuk tim Prodev: laporan penjualan, riset kompetitor, lahan komersial, dan simulator investor.

## Isi

- **Sales Report**: tren penjualan, profil pembeli, channel, tipe rumah, dan tim sales.
- **Market Research**: peta developer, tangga harga, dan posisi produk.
- **Lahan Komersial**: site plan, daftar kavling, dan penawaran tenant.
- **Simulator Investor**: perbandingan beli vs sewa, BEP, dan proyeksi omzet & laba.

## Menjalankan

Buka `index.html` di browser. Tanpa pengaturan apa pun, dashboard berjalan dengan data contoh.

Data di repo ini adalah data contoh (dummy). Panduan pemasangan dan pengaturan disimpan terpisah, tidak di repo ini.
